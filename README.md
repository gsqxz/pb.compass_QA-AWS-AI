# AWS & AI for Software Quality Engineering - Compass UOL

Este repositório documenta meu aprendizado, atividades e projetos desenvolvidos durante o Programa de Bolsas de QA da Compass UOL, dividido em duas fases.

## Sobre o Programa

O programa de bolsas da Compass UOL oferece trilhas de treinamento personalizadas em tecnologias e frameworks de ponta, com possibilidade de efetivação ao final. Dentre as diversas frentes de aprendizado, este espaço documenta a trilha de AWS & AI for Software Quality Engineering. O programa capacita os bolsistas para o mercado de Qualidade de Software, guiando-os desde o aprendizado de frameworks essenciais até a aplicação prática em projetos de desenvolvimento. A experiência é imersiva, envolvendo metodologias ágeis, trabalho em equipe e o aprimoramento contínuo de hard e soft skills.
